| Type                            | How it learns                                                | Example                                                               |
| ------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------- |
| **Supervised learning**         | Learns from labeled examples: input → correct answer         | Predicting whether an email is spam                                   |
| **Unsupervised learning**       | Finds patterns/structure in data without given answers       | Grouping customers into similar segments                              |
| **Reinforcement learning (RL)** | Learns by taking actions and receiving rewards/penalties     | An AI learning to play chess                                          |
| **Semi-supervised learning**    | Uses a small amount of labeled data + lots of unlabeled data | Classifying millions of images when only some are labeled             |
| **Self-supervised learning**    | Creates its own "labels" from the data                       | An LLM predicting the next word in a sentence                         |
| **Weakly supervised learning**  | Learns from noisy, incomplete, or imperfect labels           | Training from web pages where labels aren't always reliable           |
| **Active learning**             | The model chooses which examples it wants labeled            | An image classifier asking a human to label the most uncertain images |
| **Online learning**             | Continuously learns as new data arrives                      | A recommendation system adapting to your latest behavior              |
